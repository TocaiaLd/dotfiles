# Simple Waybar - TocaiaLd
A simple waybar theme based on terminal applications (TUIs).

![Bar](https://github.com/TocaiaLd/simple-waybar/blob/main/theme.jpeg)

#### Installation
```bash 
$ mkdir -p ~/.config/waybar
$ git clone https://github.com/TocaiaLd/simple-waybar.git ~/.config/waybar
```

#### Dependencies
- waybar
- btop
- mpd
- rmpc
- networkmanager
- yay 
- wifitui-bin
- bluetui
- rofi
- JetBrainsMono Nerd Font
- wl-copy
- cliphist
