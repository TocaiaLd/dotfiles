# Dotfiles

Simple configuration for my personal computers, separated between my Lenovo ThinkPad T495 and desktop.

## Installation

### Running
Clone the repository and run the following commands, according with the PC:

```bash
# Laptop
$ git clone https://github.com/TocaiaLd/dotfiles.git 
$ chmod +x ./dotfiles/setup-laptop.sh
$ sudo ./dotfiles/setup-laptop.sh
```

```bash
# Desktop
$ git clone https://github.com/TocaiaLd/dotfiles.git 
$ chmod +x ./dotfiles/setup-desktop.sh
$ sudo ./dotfiles/setup-desktop.sh
```
