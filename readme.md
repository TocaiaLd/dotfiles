# Dotfiles

Simple configuration for my personal computers, separated between my Lenovo ThinkPad T495 and desktop.

## Installation

Clone the repository and run `setup.sh`:

```bash
$ git clone https://github.com/TocaiaLd/dotfiles.git && bash setup.sh
```
